## 3. 风险与应对

| 风险 | 概率 | 影响 | 应对措施 |
|------|------|------|---------|
| Gemini API 调用有问题 | 中 | 高 | 提前测试 API，准备 fallback |
| Cloudflare Pages 构建失败 | 低 | 中 | 本地先 build 测试 |
| 域名 DNS 生效慢 | 中 | 低 | 提前配置，等生效 |
| UI 效果不满意 | 高 | 中 | 快速迭代，先上线再优化 |
| 时间不够 | 中 | 中 | 砍非核心功能，保证核心流程 |
