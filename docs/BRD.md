# BRD - 商业需求文档

**产品名称**：Goodbye Startup  
**版本**：v1.0 (MVP)  
**日期**：2026-08-05  
**作者**：AI Agent

---

## 1. 项目背景

### 1.1 市场机会

- 全球有大量想创业但不敢辞职的白领/程序员/学生
- 创业成本高、失败率高，大多数人需要低成本试错
- AI 技术成熟，可以模拟真实创业场景
- 现有创业教育内容太理论，缺乏沉浸式体验

### 1.2 问题

- 想创业的人缺乏真实体感，不知道创业到底是什么样
- 市面上的创业课程太贵、太理论、不互动
- 直接创业风险太高，很多人想先"模拟"一下
- 游戏化的创业模拟工具很少，且大多是纯游戏，不够真实

### 1.3 机会

- 用 AI 做一个"创业压力测试器"，让用户低成本体验创业
- 游戏化 + 教育结合，既有娱乐性又有学习价值
- 美国市场付费习惯好，$10/月定价用户能接受
- 冷启动渠道多（Product Hunt, Reddit, Twitter, Indie Hackers）

---

## 2. 产品愿景

**让每个人在真正创业前，先体验一次真实的创业失败。**

### 2.1 长期愿景

- 成为最好的创业模拟/教育平台
- 扩展到不同行业、不同阶段的创业模拟
- 建立创业者社区
- 企业版（用于创业培训、MBA 教学）

### 2.2 MVP 目标

- 验证核心需求：用户是否愿意为"创业模拟"付费
- 验证产品形态：对话式 + 游戏化是否有粘性
- 验证获客渠道：能否通过 Product Hunt / Reddit 获得初始用户

## 3. 目标用户

### 3.1 核心用户画像

| 维度 | 描述 |
|------|------|
| **年龄** | 25-35 岁 |
| **地域** | 美国为主，中国为辅 |
| **身份** | 大厂员工 / 程序员 / 商学院学生 / 想做 side hustle 的上班族 |
| **收入** | $50k-$150k/年 |
| **痛点** | 想创业但不敢辞职、没经验、怕踩坑、需要低成本试错 |
| **心态** | 对创业有浪漫想象，但缺乏真实体感 |
| **付费意愿** | 愿意为"学习 + 娱乐"付 $10-30/月 |

### 3.2 用户分层

| 层级 | 特征 | 占比 |
|------|------|------|
| **好奇者** | 随便玩玩，体验一下 | 60% |
| **认真者** | 真的在考虑创业，想测试想法 | 30% |
| **创业者** | 已经在创业，想用来做决策参考 | 10% |

## 4. 商业模式

### 4.1 定价策略

| 套餐 | 价格 | 内容 |
|------|------|------|
| **Free** | $0 | 免费玩 1 次完整模拟 |
| **Pro** | $9.99/月 或 $49.99/一次性 | 无限模拟、所有赛道、高级复盘 |
| **Team** | $29/月（后续） | 多人模拟、团队对战 |

### 4.2 付费墙位置

- 用户完成第 1 次完整模拟（180天）后
- 想开始第 2 次模拟时触发付费墙
- 文案："想再试一次？升级 Pro 无限玩"

### 4.3 收入预测（MVP 阶段）

- MVP 阶段不追求收入，先验证需求
- 目标：100 个用户，5% 付费转化率
- 月收入目标：$50-$100（验证付费意愿即可）

## 5. 竞争分析

### 5.1 直接竞品

| 产品 | 类型 | 优势 | 劣势 |
|------|------|------|------|
| **Startup Company** | 游戏 | 游戏性强 | 纯游戏，不够真实 |
| **Business Simulation** | 教育软件 | 专业 | 太贵、太复杂 |
| **ChatGPT 套壳** | AI 工具 | 灵活 | 没有游戏化、留存差 |

### 5.2 我们的差异化

1. **AI 驱动**：不是预设剧情，每次都不一样
2. **数据真实**：基于真实市场数据，不灌鸡汤
3. **游戏化**：有进度、有数值、有成就感
4. **价格低**：$9.99/月，比传统创业课程便宜太多

## 6. 成功指标

### 6.1 MVP 成功标准

| 指标 | 目标 |
|------|------|
| 技术跑通 | ✅ 网站正常访问，对话流程完整 |
| 用户验证 | 100 个真实用户使用 |
| 付费验证 | 至少 5 个人点击付费按钮（即使是假的） |
| 留存验证 | 20% 用户完成第 1 次完整模拟 |

### 6.2 长期指标（MVP 后）

- DAU / MAU
- 付费转化率
- 用户留存（7日 / 30日）
- 每次模拟平均时长
- NPS 评分

## 7. 风险与应对

| 风险 | 概率 | 影响 | 应对 |
|------|------|------|------|
| 用户觉得"就是个 ChatGPT 套壳" | 中 | 高 | 强化游戏化元素、数值系统、剧情感 |
| Gemini API 成本太高 | 低 | 中 | 优化 prompt、控制 token 用量、免费版限制次数 |
| 国内访问慢 | 高 | 低 | MVP 主要做美国市场，国内后续优化 |
| 付费转化率低 | 中 | 高 | 优化付费墙位置、增加 Pro 功能、调整定价 |
