# Product contract

Updated 2026-11-09. Supersedes the archived MVP requirements.

1. English is the SSR default; browser language and saved preference are applied after hydration. Switching to Chinese updates all subscribed UI without navigation or losing input. AI output follows the language of each new request; earlier generated text is not retroactively translated.
2. Setup accepts an idea (1–2000 characters), cash ($1–10 million), monthly costs ($0–1 million), team (1–50), and part/full-time commitment. No account is required.
3. Six successful stages: simulated Day 0, 5, 90, 120, 150 and 180. All day references describe simulated time; actual use is about 15 minutes. Cash exhaustion can end the run early.
4. UI distinguishes AI assumptions from calculated metrics, exposes the proposed inputs, and offers three choices and free-form decisions. A single historical view groups local decisions, AI notes and assumptions under recorded cash stages. Missing local records are marked. The final scenario verdict and downloadable review use settled metrics. No live market research is claimed.
5. An anonymous browser has one free run each device-local calendar day, used on the first successful AI reply. The server validates the device time zone and computes local midnight using its own clock. A time-zone change takes effect after the current allowance period. Continuing an older run does not consume today’s eligibility; its attempt cap does not reset. Unstarted drafts renew failed-attempt allowance each local day. Failed inference does not advance state but counts toward the 10-attempt maximum. Clearing cookies/device changes can create a new identity; no natural-person enforcement is promised.
6. Errors preserve the decision. A lost response keeps its request ID and original decision for explicit retry. Replay returns numerical state and confirms the original locally saved decision for its stage. AI text missing from the browser stays unavailable. A damaged local transcript can be exported as raw text for recovery. A separate draft stays in the current tab, including across refresh, and can be submitted only after resolving the original request. Refresh reconciles the current server version. The browser transcript is exportable as JSON; old or corrupt saves cannot import authority.
7. Numerical save expiry is 30 days since successful progression, or creation for a draft. Daily eligibility renews at device-local midnight; quota metadata expires 180 days after the latest allocation renewal or first success. Expiry/deletion/abandonment does not refund that day’s used eligibility. Physical purge is daily plus opportunistic.
8. A second simulation checks current daily eligibility. An eligible completed run can be atomically replaced by submitting new settings, with the old ID as a guard; cancellation or conflict preserves the previous record. Pricing displays the free option. There is no checkout, subscription, billing portal or refund workflow.
9. Retain all 15 public paths and editorial topics. Mathematical examples are labeled hypothetical; sourced definitions and statistics must retain scope/date. RSS stays a static generated asset. Chinese text uses “一次模拟”; 工作原理 contains the simulated-time/15-minute clarification wherever stage days appear.

Acceptance: normal flow, early bankruptcy, duplicate/late/concurrent requests, failed provider, denied/corrupt storage, reload, export, language, IME, mobile overflow, ownership, origin, expiry, quota, all public metadata and machine-readable content. Tests use local fixtures; a paid provider evaluation and deployed preview are distinct release gates.
