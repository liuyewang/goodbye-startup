# Product contract

Updated 2026-11-09. Supersedes the archived MVP requirements.

1. English is the SSR default; browser language and saved preference are applied after hydration. Switching to Chinese updates all subscribed UI without navigation or losing input. AI output follows the language of each new request; earlier generated text is not retroactively translated.
2. Setup accepts an idea (1–2000 characters), cash ($1–10 million), monthly costs ($0–1 million), team (1–50), and part/full-time commitment. No account is required.
3. Six successful stages: simulated Day 0, 5, 90, 120, 150 and 180. All day references describe simulated time; actual use is about 15 minutes. Cash exhaustion can end the run early.
4. UI distinguishes AI assumptions from calculated metrics, exposes the proposed inputs, offers three choices and free-form decisions, and shows a timeline and final scenario verdict. No live market research is claimed.
5. An anonymous browser allocation has one free run, used on first successful AI reply. Failed inference does not advance state but counts toward the 10-attempt maximum. Clearing cookies/device changes can create a new identity; no natural-person enforcement is promised.
6. Errors preserve the decision. A lost response keeps its request ID for replay; replay returns numerical state, not unavailable server-side text. Refresh reconciles the current server version. Text is local-only and exportable as JSON; old/corrupt saves cannot import authority.
7. Numerical save expiry is 30 days since successful progression, or creation for a draft. Quota expiry is 180 days from first success; unused allocations expire 180 days from creation. Expiry/deletion/abandonment does not refund used eligibility. Physical purge is daily plus opportunistic.
8. A second simulation shows eligibility information. Pro/Lifetime are explicitly unavailable future plans with no confirmed price, checkout, subscription, billing portal or refund promises.
9. Retain all 15 public paths and editorial topics. Mathematical examples are labeled hypothetical; sourced definitions and statistics must retain scope/date. RSS stays a static generated asset. Chinese text uses “一次模拟”; 工作原理 contains the simulated-time/15-minute clarification wherever stage days appear.

Acceptance: normal flow, early bankruptcy, duplicate/late/concurrent requests, failed provider, denied/corrupt storage, reload, export, language, IME, mobile overflow, ownership, origin, expiry, quota, all public metadata and machine-readable content. Tests use local fixtures; a paid provider evaluation and deployed preview are distinct release gates.
