## 1. 产品概述

### 1.1 产品定位

一个数据驱动的 AI 创业模拟器，用户输入创业想法，AI 导师用 180 天模拟时间，基于真实市场数据，带用户体验从想法到上线到成败的全过程。

### 1.2 核心价值

- **低成本试错**：不用真的辞职、不用真的花钱，就能体验创业的残酷
- **数据驱动**：基于真实行业数据，不是鸡汤，是现实
- **游戏化体验**：像玩游戏一样学创业，有沉浸感
- **AI 个性化**：每个创业想法都有不同的模拟结果

### 1.3 目标用户

美国 25-35 岁想创业的白领 / 程序员 / 学生。

## 3. 用户流程

### 3.1 新用户流程

```
Landing 页
  ↓
点击 "Start Your Startup Journey"
  ↓
进入模拟器
  ↓
AI 导师开场："创业压力测试模式已启动..."
  ↓
用户输入创业想法
  ↓
开始 180 天模拟
  ├─ 第 1-5 天：想法解构 + 市场审视
  ├─ 第 60-90 天：产品上线 + 初始数据
  ├─ 第 91-180 天：用户行为 + 财务困境

第 1 次模拟结束
```

## 5. AI 导师设定

### 5.1 角色

- **称呼**：Coach（创业压力测试员）
- **风格**：专业、冷静、直言不讳、数据驱动
- **态度**：不灌鸡汤，说真话，偶尔毒舌
- **背景**：连续创业者，见过太多失败

### 5.2 系统提示词

详见 `lib/prompts/` 目录。

**核心规则**：
1. 基于悲观但真实的数据基准
2. 严格按天数推进剧情
3. 关键决策点让用户选择
4. 评估用户的决策，给出现实的结果
5. 不直接给答案，引导思考

### 5.3 数据基准

| 指标 | 基准值 |
|------|--------|
| 社区推广点击率 | 0.5% - 2% |
| 网站注册转化率 | 1% - 3% |
| 免费转付费转化率 | 0.5% - 2% |
| 月流失率 | 10% - 20% |
| CAC（B2C） | $50 - $500 |
| CAC（B2B） | $500 - $5000 |

## 6. 多语言

### 6.1 语言策略

- 默认英文（主要市场）
- 自动检测浏览器语言
- 右上角手动切换按钮
- UI 文案双语，AI 对话语言跟随 UI 语言

### 6.2 翻译范围

- ✅ 所有 UI 文案
- ✅ 系统提示词（英文为主，中文翻译版）
- ✅ 静态页面内容
- ❌ AI 生成的对话内容（由 AI 自动用对应语言回复）

## 7. 非功能需求

### 7.1 性能

- 首屏加载 < 3s（美国地区）
- API 响应 < 10s（Gemini 生成时间）
- 页面切换无明显卡顿

### 7.2 兼容性

- 支持主流浏览器：Chrome、Safari、Firefox、Edge
- 移动端适配：iPhone、Android
- 响应式断点：sm/md/lg/xl

### 7.3 安全

- API Key 不暴露在前端
- 防止 API 滥用（简单的速率限制）
- 用户数据本地存储，不上传敏感信息

### 7.4 SEO

- 基础 SEO 配置（title、description）
- Open Graph 标签
- 结构化数据（可选）
